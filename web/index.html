RP2350-Touch-AMOLED-1.75 edition · 151-Pokémon tamagotchi

1Flash the RP2350

RP2350: the old ESP32 Web Tools manifest is deliberately not used here. Flash with pico⚡flash, which supports RP2040/RP2350 over WebUSB.

Download the latest .uf2 firmware from this repository's Actions/Release build, then open pico⚡flash, connect the board and drop the UF2 on it.

Chrome/Edge or another Chromium browser is required for WebUSB. Put the board in BOOTSEL mode before connecting it if pico⚡flash does not see it automatically.

2Load the sprites to microSD

Keep the board running normally, connect its USB serial port, then press Connect board. The page sends the same PUT protocol used by the firmware tools, including the Pokédex thumbnails.

Do not use the pico⚡flash page and the serial uploader at the same time: only one browser program should own the USB connection. Restart the board after the transfer.






What is included


The RP2350 build uses the Waveshare QSPI AMOLED driver, CST9217 touch, AXP2101/PCF85063 power+RTC, ES8311 audio through Arduino-Pico PIO I²S, and SD sprite loading with a SRAM-safe cache.
